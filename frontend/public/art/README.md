# Collected artwork used in the interface

These twelve WebP files were selected from the previously assembled ParaMyth
licensed image library. They are unchanged copies, renamed for stable references.
The full original metadata is preserved in `manifest.json`, including each
source page, author, license, source filename and original dimensions.

The interface uses CSS cropping, focal positioning, masks, tint, and gradients.
Britomart anchors the landing hero; castle landscapes support the overview and
sign-in page; premise-based project covers use relevant settings. Creative and
media empty states distinguish reference art from user-generated output. Atlas
record images are explicitly labeled as visual inspiration.

The user-supplied ParaMyth logo is separate in `../brand/paramyth-logo.png` and
is not part of this public-domain/CC0 collection.
