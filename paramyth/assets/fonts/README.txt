Document export font

document-regular.ttf is a static weight 400 instance derived from Noto Sans KR.
Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
License: SIL Open Font License 1.1, reproduced in OFL.txt.
The instance was prepared with fontTools. It supplies embedded PDF glyphs for
Latin, Greek, Cyrillic, Korean and common CJK source names. PDFs subset the face.
